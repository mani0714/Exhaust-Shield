Company knowledge vs standard RAG

This compares Tab 2 only. Classic RAG finds docs and sends them to an LLM. ExhaustShield searches local files by keywords, scores each excerpt, and answers from the best hit or a human vault — no model.

RAG

DocsCleartextLLM
salary · deal $ · SSN
  • Finds relevant chunks from a knowledge base
  • Sends cleartext chunks + question to the model
  • Focuses on answer quality, not data egress
  • Risk: secrets can enter open-model context
Secrets ride the same pipe as the question

ExhaustShield

DocsWord scoreLocal / Human
keyword overlap best score → answer
  • Splits the question into words and searches local policy files
  • Scores each excerpt by keyword overlap (strong words count more)
  • High enough score → serve that text; vault hit wins first
  • Near-zero overlap → human gap — no LLM guess
Word search + score — company text never sent to a model
CEO takeaway: Tab 2 is word search and scoring on this machine — not RAG with an LLM. Classic RAG’s last stop is a model. ExhaustShield’s last stop is the highest-scoring local excerpt, the human vault, or a person.

How the Human vault works

Not every question waits on a person. Humans step in only for gaps or wrong local answers — then the fix is reused forever, off-model.

Step 01

Gap or disputed answer

No vault hit, weak doc match, or you marked a local answer incorrect.

Step 02 · Queue

Human writes the truth

Approved company answer is saved locally — never used to train an LLM.

Do NOT queueDocs matched · employee gets the answer now
DO queueMissing context or disputed local answer
After saveNext ask reuses Path A · LLM never learns it
Outcome: Humans fill knowledge gaps; open-source models do not get quietly fine-tuned on proprietary fixes.
